# Lista de exercícios em C — parte 2

Continuação de exercícios independentes em C, organizados em `Lista_Exercicios/`, com arquivos numerados de `ex44.c` a `ex69.c` e uma pasta de saída.

## Estrutura

- Arquivos `.c`: exercícios independentes (ou o programa indicado acima).
- Pastas `Lista_Exercicios/`, `Testes/` ou `output/`, quando presentes: organização dos códigos e artefatos.

## Como executar

Requisito: GCC configurado no terminal.

```bash
git clone https://github.com/Pedro-Bonelli/exercicios2_c.git
cd exercicios2_c
gcc Lista_Exercicios/ex44.c -o programa
./programa
```

No PowerShell do Windows, execute `./programa.exe` (ou `.\programa.exe`). Cada arquivo `.c` é um exercício independente, salvo indicação no próprio código.

## Observações

Compile somente o exercício que pretende executar; a pasta `output/` contém artefatos e não é necessária para compilar.
